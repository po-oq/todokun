# メモタブ 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ウィンドウ上部に「TODO」「メモ」の 2 タブを置き、メモタブでアプリ全体で 1 つのメモ（`data/memo.md`）を、TODO の右ペインと同じ操作で編集できるようにする。

**Architecture:** `DayEditorSession` の状態機械を基底 `DocumentEditorSession` に抜き出し、日の側（`DayEditorSession`）とメモの側（`MemoEditorSession`）は保存先と表示文だけを持つ。右ペインの画面部品は `DocumentPaneView` に一般化し、TODO とメモの両方で使う。ウィンドウは「タブ行＋両方を載せたまま `IsVisible` で切替える中身」にする。

**Tech Stack:** .NET 10 / Avalonia（FluentTheme・`NativeWebView`・Headless テスト）/ CommunityToolkit.Mvvm / xUnit。

**Spec:** `docs/superpowers/specs/2026-10-14-memo-tab-design.md`（仕様の正は `docs/todo-requirements.md`。食い違ったら要件が正）

## Global Constraints

- **コミット・push・PR は利用者が頼んだときだけ**（`HANDOFF.md`）。各タスクの最後の「区切り」は、コミットの目安であって実行の指示ではない。頼まれたときのメッセージ案を添える。
- **本物のデータに触れない**。手で動かすときは `--data-dir` を一時フォルダにする。
- **既存テスト（`Todokun.Tests` 281 件・`Todokun.UiTests` 34 件）を無修正で通す**。直してよいのは `FakeUiServices` の署名追従（Task 1）だけ。
- ビルドは警告 0・エラー 0 を保つ。返答・文言は日本語。
- メモのファイルは `{DataRoot}/memo.md`。UTF-8・BOM なし・LF・`AtomicFile` で書く。読むとき BOM は外し、不正バイトは `Failed`。
- **読めないメモを空として扱わない**（編集に入れない。入ると保存で元のファイルを失う）。
- Undo は範囲置換（`SelectedText`）。`TextBox.Text` の全文置換は使わない。
- 仕様の文言（画面に出す文）：メモの案内「メモはまだありません。『編集』で書けます」／見出し「メモ」／保存の確認「メモが保存されていません。保存しますか？」／削除の確認「メモのファイルを削除します。よろしいですか？」。
- md と html の計画（`docs/todokun-plan.md`／`.html`）を直すときは**対で**直す。
- ヘッドレスのテストで ViewModel の `Draft` だけを直接変えない（入力欄の文字を変える）。

## Review Focus

仕様が暗に求めるが、各タスクの主テストでは素通りしやすいもの（該当するタスクにテストを足してある）。

1. **メモが UTF-8 でない・読めない**：編集に入れず、元のファイルを書き換えない（Task 3・4）。
2. **データルートが書けない**：メモも編集に入れない（Task 4）。
3. **メモタブの `Ctrl+E` と `←→`**：TODO のセッション・選択日に影響しない（見えていない側を動かさない。Task 5）。
4. **閉じるとき両方が未保存**：TODO →メモの順に確認し、2 つ目をキャンセルしたら閉じない（Task 5・6）。
5. **メモが空のまま保存**：確認の後にファイルが消え、案内が出る。キャンセルなら残る（Task 4）。
6. **テーマ変更**：両方のプレビューが作り直される（Task 5）。
7. **`memo.md` が日ファイルの走査に混ざらない**（Task 3）。

`DocumentEditorSession.cs`（今の `DayEditorSession` から、日・`DayStore`・`DayIndex` に依存しない部分を移す）：

```csharp
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;
using Todokun.Core;

namespace Todokun.Presentation;

/// <summary>
/// 1 つの文書（日ファイル・メモ）の編集の状態（計画 11.4）。「読めない」を「ファイルなし」と混ぜない：
/// 読めない文書は編集に入れない（空から書いて保存すると元のファイルを失うため）。
/// 保存先・表示文は派生クラスが決める。画面・ダイアログは <see cref="IUiServices"/> 越し。
/// </summary>
public abstract partial class DocumentEditorSession : ObservableObject
{
    private readonly IUiServices _ui;
    private readonly Func<(bool CanWrite, string? Reason)> _writable;
    protected int _generation;   // 状態が変わるたびに増やす。確認ダイアログの後で、状態が変わっていないかを見る

    [ObservableProperty]
    private DayContent _content = new DayContent.Missing();

    [ObservableProperty]
    private EditorMode _mode = EditorMode.View;

    /// <summary>編集欄の内容。</summary>
    [ObservableProperty]
    private string _draft = "";

    /// <summary>編集を始めた時点（または最後に保存した時点）の内容。</summary>
    [ObservableProperty]
    private string _base = "";

    /// <summary>確認ダイアログを出している間。日の移動・編集への切り替えは無視する。</summary>
    [ObservableProperty]
    private bool _isConfirming;

    /// <summary>画面に出す、保存・削除・編集に入れない理由。</summary>
    [ObservableProperty]
    private string? _message;

    protected DocumentEditorSession(IUiServices ui, Func<(bool CanWrite, string? Reason)>? writable)
    {
        _ui = ui;
        _writable = writable ?? (() => (true, null));
        BeginEditCommand = new RelayCommand(() => BeginEdit(), () => CanBeginEdit);
        SaveCommand = new AsyncRelayCommand(async () => await SaveAsync());
        BackToViewCommand = new AsyncRelayCommand(async () => await LeaveEditAsync());
        PropertyChanged += (_, e) =>
        {
            if (e.PropertyName == nameof(CanBeginEdit)) BeginEditCommand.NotifyCanExecuteChanged();
        };
    }

    // ── 派生が決めるもの ──
    /// <summary>バーの見出し（日なら「2026-10-14 (水)」、メモなら「メモ」）。</summary>
    public abstract string HeaderText { get; }

    /// <summary>プレビューに出すもの。</summary>
    public abstract PreviewSource Preview { get; }

    protected abstract bool StoreExists();
    /// <summary>書く。失敗は <see cref="IOException"/>・<see cref="UnauthorizedAccessException"/> のまま上げる。</summary>
    protected abstract void StoreWrite(string text);
    protected abstract void StoreDelete();
    /// <summary>書けた直後（<see cref="Content"/> を更新した後）。日なら索引に足す。</summary>
    protected virtual void AfterWritten() { }
    /// <summary>消せた直後。日なら索引から外す。</summary>
    protected virtual void AfterDeleted() { }
    /// <summary>読めない文書を編集に入ろうとしたときの文。</summary>
    protected abstract string UnreadableMessage(string reason);
    protected abstract string AskSaveText { get; }
    protected abstract string ConfirmDeleteText { get; }

    // ── コマンド（画面の部品用） ──
    public IRelayCommand BeginEditCommand { get; }
    public IAsyncRelayCommand SaveCommand { get; }
    public IAsyncRelayCommand BackToViewCommand { get; }

    /// <summary>表示が変わった（開いた・保存した・削除した）。引数 true は同じものの作り直し。UI スレッドで呼ばれる。</summary>
    public event Action<bool>? ContentChanged;

    // ── 表示用 ──
    public bool IsEditing => Mode == EditorMode.Edit;
    public bool IsViewing => Mode == EditorMode.View;
    public bool IsDirty => Mode == EditorMode.Edit && Norm(Draft) != Norm(Base);
    public bool HasMessage => !string.IsNullOrEmpty(Message);
    public string ModeText => IsEditing ? "編集中" : "ビュー";

    /// <summary>「✎ 編集」を押せるか。読めない・データルートが書けないとき・確認中は押せない。</summary>
    public bool CanBeginEdit => IsViewing && !IsConfirming && Content is not DayContent.Failed && _writable().CanWrite;

    public static string Norm(string s) => s.Replace("\r\n", "\n");

    private static bool IsBlank(string s) => string.IsNullOrWhiteSpace(s);

    partial void OnModeChanged(EditorMode value) => RefreshDerived();
    partial void OnDraftChanged(string value) => OnPropertyChanged(nameof(IsDirty));
    partial void OnBaseChanged(string value) => OnPropertyChanged(nameof(IsDirty));
    partial void OnContentChanged(DayContent value) => OnPropertyChanged(nameof(CanBeginEdit));
    partial void OnIsConfirmingChanged(bool value) => OnPropertyChanged(nameof(CanBeginEdit));
    partial void OnMessageChanged(string? value) => OnPropertyChanged(nameof(HasMessage));

    private void RefreshDerived()
    {
        OnPropertyChanged(nameof(IsEditing));
        OnPropertyChanged(nameof(IsViewing));
        OnPropertyChanged(nameof(IsDirty));
        OnPropertyChanged(nameof(ModeText));
        OnPropertyChanged(nameof(CanBeginEdit));
    }

    /// <summary>読んだ内容をビューモードで出す。派生の「開く」「読み込む」から呼ぶ（呼ぶ側が <c>_generation++</c> を済ませる）。</summary>
    protected void ShowContent(DayContent content)
    {
        Content = content;
        Mode = EditorMode.View;
        Draft = Base = "";
        Message = null;
        ContentChanged?.Invoke(false);
    }

    // ── 編集へ ──

    /// <summary>編集に入る（冪等。既に編集中・確認中なら何もしない）。入れなければ理由を <see cref="Message"/> に出す。</summary>
    public bool BeginEdit()
    {
        if (IsConfirming) return false;
        if (Mode == EditorMode.Edit) return true;
        if (Content is DayContent.Failed failed)
        {
            Message = UnreadableMessage(failed.Reason);
            return false;
        }
        var (canWrite, reason) = _writable();
        if (!canWrite)
        {
            Message = $"データの保存先に書き込めないため、編集できません：{reason}";
            return false;
        }
        _generation++;
        var text = Content is DayContent.Loaded l ? l.Text : "";
        Base = Draft = text;
        Message = null;
        Mode = EditorMode.Edit;
        return true;
    }

    public void SetDraft(string text) => Draft = text;

    // ── 保存 ──

    public async Task<SaveResult> SaveAsync()
    {
        if (IsConfirming) return SaveResult.Cancelled;
        return await SaveCoreAsync();
    }

    private async Task<SaveResult> SaveCoreAsync()
    {
        if (Mode != EditorMode.Edit) return SaveResult.Cancelled;
        if (!IsDirty) return SaveResult.NoChange;

        if (!IsBlank(Draft))
        {
            try
            {
                StoreWrite(Draft);
            }
            catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
            {
                Message = $"保存できませんでした：{ex.Message}";
                return SaveResult.Failed;
            }
            _generation++;
            Content = new DayContent.Loaded(Norm(Draft));
            Base = Draft;
            Message = null;
            AfterWritten();
            ContentChanged?.Invoke(true);
            return SaveResult.Saved;
        }

        // 空（空白・改行だけ）で保存
        if (!StoreExists())
        {
            Base = Draft;   // 何も作らない。確認も出さない
            return SaveResult.NoChange;
        }

        var gen = _generation;
        IsConfirming = true;
        bool ok;
        try
        {
            ok = await _ui.ConfirmDeleteAsync(ConfirmDeleteText);
        }
        finally
        {
            IsConfirming = false;
        }
        if (!ok || gen != _generation) return SaveResult.Cancelled;

        try
        {
            StoreDelete();
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            Message = $"削除できませんでした：{ex.Message}";
            return SaveResult.Failed;   // Content・索引・Base は変えない
        }
        _generation++;
        Content = new DayContent.Missing();
        Base = Draft;
        Message = null;
        AfterDeleted();
        ContentChanged?.Invoke(true);
        return SaveResult.Deleted;
    }

    // ── ビューに戻る・閉じる ──

    /// <summary>
    /// 編集から出る（Esc・Mod+E・ボタン・別の日・閉じる）。変更が無ければそのまま。未保存なら「保存しますか？」。
    /// ビューモードになった（または元からビュー）なら true。キャンセル・保存の失敗・確認中なら false（編集に留まる）。
    /// </summary>
    public async Task<bool> LeaveEditAsync()
    {
        if (IsConfirming) return false;
        if (Mode == EditorMode.View) return true;
        if (!IsDirty)
        {
            ToView();
            return true;
        }

        var gen = _generation;
        IsConfirming = true;
        SaveChoice choice;
        try
        {
            choice = await _ui.AskSaveAsync(AskSaveText);
        }
        finally
        {
            IsConfirming = false;
        }
        if (gen != _generation || Mode != EditorMode.Edit) return false;   // 確認の間に状態が変わっていたら何もしない

        switch (choice)
        {
            case SaveChoice.Discard:
                Draft = Base;
                ToView();
                return true;
            case SaveChoice.Save:
                var r = await SaveCoreAsync();
                if (r is SaveResult.Saved or SaveResult.Deleted or SaveResult.NoChange)
                {
                    ToView();
                    return true;
                }
                return false;   // 失敗・途中のキャンセル：編集に留まる
            default:
                return false;
        }
    }

    private void ToView()
    {
        _generation++;
        Mode = EditorMode.View;
    }

    /// <summary>ウィンドウを閉じてよいか（「ビューに戻る」と同じ確認。保存・削除に失敗したら閉じない）。</summary>
    public Task<bool> CanCloseAsync() => LeaveEditAsync();
}
```

```csharp
using System.Globalization;
using CommunityToolkit.Mvvm.ComponentModel;
using Todokun.Core;

namespace Todokun.Presentation;

/// <summary>1 日分の編集の状態（計画 11.4）。共通の状態機械は <see cref="DocumentEditorSession"/>。</summary>
public sealed partial class DayEditorSession : DocumentEditorSession
{
    private static readonly string[] Weekdays = ["日", "月", "火", "水", "木", "金", "土"];

    private readonly DayStore _store;
    private readonly DayIndex _index;

    [ObservableProperty]
    private DateOnly _day;

    public DayEditorSession(DayStore store, DayIndex index, IUiServices ui, Func<(bool CanWrite, string? Reason)>? writable = null)
        : base(ui, writable)
    {
        _store = store;
        _index = index;
    }

    public string DayText => $"{Day:yyyy-MM-dd} ({Weekdays[(int)Day.DayOfWeek]})";
    public override string HeaderText => DayText;

    partial void OnDayChanged(DateOnly value)
    {
        OnPropertyChanged(nameof(DayText));
        OnPropertyChanged(nameof(HeaderText));
    }

    protected override bool StoreExists() => _store.Exists(Day);
    protected override void StoreWrite(string text) => _store.Write(Day, text);
    protected override void StoreDelete() => _store.Delete(Day);
    protected override void AfterWritten() => _index.Add(Day);
    protected override void AfterDeleted() => _index.Remove(Day);
    protected override string UnreadableMessage(string reason) => $"この日のファイルは読めないため、編集できません：{reason}";
    protected override string AskSaveText => "この日のメモが保存されていません。保存しますか？";
    protected override string ConfirmDeleteText => "この日のファイルを削除します。よろしいですか？";

    // ── 日を開く（View） ──

    /// <summary>その日を読んで、ビューモードで開く。呼ぶ前に、編集中の確認は済んでいること（<see cref="TryOpenDayAsync"/>）。</summary>
    public void Open(DateOnly day)
    {
        _generation++;
        Day = day;
        ShowContent(_store.Read(day));
    }

    /// <summary>
    /// 別の日を開く（要求 → 確認 → 確定の「確認」と「開く」）。編集中で未保存なら「保存しますか？」を出す。
    /// 開けたら true（呼び出し側は選択を確定する）。確認中・キャンセル・保存の失敗なら false。
    /// </summary>
    public async Task<bool> TryOpenDayAsync(DateOnly day)
    {
        if (IsConfirming) return false;
        if (!await LeaveEditAsync()) return false;
        Open(day);
        return true;
    }

    // ── プレビューに出すもの ──

    public override PreviewSource Preview => Content switch
    {
        DayContent.Loaded l => new PreviewSource.Markdown(l.Text, Path.GetDirectoryName(_store.PathOf(Day))!, _store.PathOf(Day),
```

```csharp
using System.Text;

namespace Todokun.Core;

/// <summary>厳密な UTF-8 のテキストファイル（BOM は読むとき外す。書くときは LF・BOM なし・アトミック）。</summary>
public static class Utf8TextFile
{
    // 厳密な UTF-8。既定のデコーダーは不正なバイトを U+FFFD に置き換えてしまい、元に戻せない。
    private static readonly UTF8Encoding Strict = new(false, throwOnInvalidBytes: true);

    /// <summary>ファイルが無ければ <see cref="DayContent.Missing"/>。読めない・UTF-8 でないなら <see cref="DayContent.Failed"/>。</summary>
    public static DayContent Read(string path)
    {
        try
        {
            if (!File.Exists(path)) return new DayContent.Missing();
            var bytes = File.ReadAllBytes(path);
            var start = bytes.Length >= 3 && bytes[0] == 0xEF && bytes[1] == 0xBB && bytes[2] == 0xBF ? 3 : 0;
            return new DayContent.Loaded(Strict.GetString(bytes, start, bytes.Length - start));
        }
        catch (DecoderFallbackException)
        {
            return new DayContent.Failed("UTF-8 として読めません");
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            return new DayContent.Failed(ex.Message);
        }
    }

    /// <summary>LF に統一し、BOM なしの UTF-8 で、アトミックに書く。失敗は例外（IOException など）。</summary>
    public static void Write(string path, string text) =>
        AtomicFile.WriteAllText(path, text.Replace("\r\n", "\n"));
}
```

```csharp
namespace Todokun.Presentation;

/// <summary>
/// Ctrl/Cmd+E の「入る／戻る」（要件 13.2・計画 11.6）。ビューでは常に「編集に入る」（冪等）。編集中は、
/// 編集に入った直後（<see cref="WindowMs"/> 以内）の再入力を、同じ押下の二重到達として戻さない。
/// </summary>
public sealed class ModEToggle(DocumentEditorSession session, Func<long> nowMs)
{
    /// <summary>別の経路から同じキーが届いたとみなす間（ms）。P0：2 経路の遅れは 0.2〜0.5ms（最初の数回は 5〜34ms）。</summary>
    public const long WindowMs = 50;

    private long _beganAt = long.MinValue;

    /// <summary>ページ（WebView）経路の BeginEdit。ビューのときだけ効く。</summary>
    public void OnPageBeginEdit()
    {
        if (session.IsViewing && session.BeginEdit()) _beganAt = nowMs();
    }

    /// <summary>ウィンドウ経路の Mod+E。処理したら true（画面は <c>Handled</c> にする）。確認中は false。</summary>
    public bool OnModE()
    {
        if (session.IsConfirming) return false;
        if (session.IsViewing)
        {
            if (session.BeginEdit()) _beganAt = nowMs();
            return true;
        }
        if (nowMs() - _beganAt < WindowMs) return true;
        _ = session.LeaveEditAsync();
        return true;
    }
}
```

```csharp
        if (Memo.Editor.IsDirty)
        {
            SelectTab(AppTab.Memo);
            if (!await Memo.Editor.CanCloseAsync()) return false;
        }
        return true;
```

```csharp
    public bool OnWindowKey(AppKey key, bool fromWebView)
    {
        var onMemo = SelectedTab == AppTab.Memo;
        if ((onMemo ? Memo.Editor : Editor).IsConfirming) return false;
        switch (key)
        {

                return true;   // 端でも食う
            case AppKey.ModE:
                return onMemo ? Memo.OnModE() : _modE.OnModE();
```
